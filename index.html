Printable booklets from Markdown.

PrintFold lays out Markdown as a printable, signature-based booklet — with imposition, custom fonts, and PDF export.

Get PrintFold See features

Simple markdown publishing

  • ↴

    Markdown support

    Write in Markdown — headings, lists, footnotes and GFM syntax.

  • ⊞

    Booklet editing

    Signature-based imposition with fold and cut marks, multi-row sheets, and a visual spread editor.

  • Aa

    Custom fonts

    Use your own .ttf, .otf or .woff files, plus system and Google Fonts, embedded into the exported PDF.

  • ⟲

    Reflow options

    Adjust margins, typography and spacing; text repaginates and H1s start on a recto.

  • ⬡

    Static spreads & regions

    Add covers, images and shapes, or flow text through custom polygon regions.

  • ⤓

    PDF export

    Export a print-ready PDF as a folded booklet, double-sided pages, or single-sided sheets.

How it works

1

Add Markdown files

Add one or more .md files; they flow together in order.

2

Set the layout

Choose fonts, set margins, design covers, and configure booklet settings.

3

Export and fold

Generate an imposed PDF, print duplex, fold along the marks, and bind the signatures.
